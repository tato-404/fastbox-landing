# FastBox

Landing page e conceito de mercado autônomo voltado para condomínios.

## Sobre o projeto

O FastBox é um projeto conceitual desenvolvido para apresentar a proposta de um mercado autônomo aplicado ao ambiente condominial.

O objetivo do projeto foi explorar interface, experiência do usuário e construção de uma landing page moderna.

## Tecnologias utilizadas

- React
- TypeScript
- Tailwind CSS
- Git
- GitHub
